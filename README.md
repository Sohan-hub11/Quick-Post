# Quick-Post

A simple, fast and intuitive web app for posting content online.  
Built with HTML, CSS, ReactJs.

---

## 🔍 About

Quick-Post is designed to let users quickly create and publish posts with minimal friction. It’s ideal as a micro-blogging front end or lightweight CMS for small projects. The idea is to keep things fast, clean and easy to deploy.

---

## ✅ Features

- Responsive UI (mobile + desktop)
- Users can create and delete posts instantly with real-time UI updates.
- Used React Hooks + Context API for simple and clean state management.
- Built a responsive UI using Bootstrap components and grid system.
- Designed the app with modular, reusable React components for better structure.

---

## 🧰 Tech Stack

- **Frontend**: ReactJs
- **Styling**: CSS Modules / Styled Components / plain CSS (adjust as per your setup).
- **Hosting / Deployment**: You can deploy on platforms like Heroku, Vercel, Firebase Hosting, etc.
- **Version Control**: Git + GitHub
